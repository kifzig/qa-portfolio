AI Job Application Assistant Core Skill Evidence

Personal project · Python, Playwright, Anthropic API (Claude), BeautifulSoup, pypdf

A Python tool that automates parts of my own job search: it takes a job posting URL, drives a real Chromium browser with Playwright to load and save the page, strips it down to plain text, and sends it to Claude to extract structured data — job title, company, location, and requirements. It then scores how well a given resume matches the posting (with Claude reasoning through pros and cons), generates a tailored cover letter, produces a skills-match summary highlighting gaps to address, and logs every application to a tracking spreadsheet.

What this demonstrates:

  • Real Playwright usage — browser automation, not just a tutorial exercise
  • Programmatic use of the Claude/Anthropic API: prompt design, structured extraction, and grounding generated content in real source data to avoid fabricated claims
  • Parsing and validating data from multiple formats (HTML, PDF) before trusting it downstream

Source isn't public — it stores my own API key and personal application data — but I'm glad to walk through the code directly, or put together a sanitized public version on request.
